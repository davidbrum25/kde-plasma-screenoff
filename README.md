# apagar-pantallas

Turn off all monitors on KDE Plasma (Wayland) **without** Plasma changing your display configuration, so windows and layout stay as they were when you wake them.

Wake: move the mouse or press any key.

## Install
```
./install.sh
```
Then add a hotkey: System Settings > Keyboard > Shortcuts > search "Apagar pantallas" (e.g. Meta+Shift+L).

## Requirements
`kscreen-doctor` (part of KDE Plasma 6).
